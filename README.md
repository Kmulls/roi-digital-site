# Roi Digital Consulting: landing page

Static site: `index.html`, `audio/` (Kevin's narration), `favicon.svg`. No build step.

## Deploy (Netlify)
1. Drag this folder onto https://app.netlify.com/drop, or connect this repo in Netlify.
2. Site settings > Domain management > Add your domain, then follow Netlify's DNS steps at your registrar.
3. Forms: the Speed Test form uses Netlify Forms (`speed-test`). Turn on email notifications under Site settings > Forms.
